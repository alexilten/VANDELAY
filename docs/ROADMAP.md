# Vandelay: Roadmap

The roadmap is a sequence of **gated phases**. A phase is done when its gate is met, not when its time window ends. Time windows are targets measured from the start of the project.

See [VISION.md](./VISION.md) for the why.

## Overview

| Phase | Window | Theme | Gate |
| --- | --- | --- | --- |
| 0 | Months 0–6 | Foundation | A stranger gets three home options from a prompt in under five minutes. |
| 1 | Months 6–18 | Home on a real site | First paid packages and a signed vendor partnership. |
| 2 | Years 1.5–3 | Network | Not yet defined. |
| 3 | Years 3–5 | Delivery brain | Not yet defined. |
| 4 | Years 5–10 | Compiler | Not yet defined. |

## Phase 0 · Foundation (months 0–6)

- Repo and monorepo setup.
- `packages/kernel`: intent schema, geometry, rules library, studies.
- Homepage (`apps/web`): the "What would you like to build?" front door.
- Venue engine behind the tool API.
- Home engine v0 on a sloped lot.

**Gate:** a stranger gets three home options from a prompt in under five minutes.

## Phase 1 · Home on a real site (months 6–18)

- Parcel, terrain and zoning for one region (region still open).
- Two or three modular vendor catalogs.
- A cost estimate.
- A permit set stamped by partner architects.

**Gate:** first paid packages and a signed vendor partnership.

## Phase 2 · Network (years 1.5–3)

- Vendor marketplace with quotes.
- More regions.
- Business and Mixed-use engines.
- Pro mode.
- IFC export tested in Revit.

## Phase 3 · Delivery brain (years 3–5)

- Fabrication files.
- Schedules and changes carried through to site.

## Phase 4 · Compiler (years 5–10)

- Intent to permit to factory.
- Automated permit checks.
- An engine SDK for third parties.

## Open decisions that affect the roadmap

These are **still open**:

- **Launch region**, which Phase 1 depends on (California is likely, not confirmed).
- **First paying customer** (homeowner, vendor or studio), which shapes the Phase 1 gate.
- **Founding team** (someone from modular construction and a licensed architect).
- **Funding path:** pre-seed on the demo and vision, or first revenue first.
- **Final name**, which must be settled before any public launch.
- **Gates for Phases 2–4**, which have not been set.
